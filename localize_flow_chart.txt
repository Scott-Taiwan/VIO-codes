Key Design Points
-----------------
- Startup is expensive (FLANN KD-tree build) but done once — suitable for pre-takeoff initialization
- Phase 1 is fast (KD-tree already built), narrows thousands of tiles down to 5 candidates
- Phase 2 is precise — SIFT + RANSAC homography on a 3×3 stitched tile patch gives sub-pixel GPS accuracy
- GPU/CPU path is selected at runtime based on available RAM; same logic applies to both SIFT extraction and descriptor matching
